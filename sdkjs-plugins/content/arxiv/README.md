# arXiv Plugin

This plugin allows you to search and cite arXiv papers directly in ONLYOFFICE editors. It provides an easy way to insert citations and generate bibliographies in various citation styles.

## Features

- Search arXiv papers using standard arXiv search syntax
- Preview paper title, authors, publication date and abstract
- Insert citations with customizable citation styles
- Generate and update bibliography automatically 
- Support for multiple citation styles and languages

## Installation

1. Download the plugin from the ONLYOFFICE plugin marketplace
2. Install it in your ONLYOFFICE editor

## Usage

1. Search Papers
   - Enter search query using arXiv search syntax (e.g. "au:Einstein" for author, "ti:quantum" for title, "cat:physics" for category)
   - Browse through paginated results (10 papers per page)
   - Results are sorted by relevance by default
   - View paper details including title, authors, publication date and abstract

2. Insert Citations
   - Select papers by checking the checkbox
   - Choose your preferred citation style
   - Select language for citations
   - Click "Insert Citation" to add the citation to your document

3. Generate Bibliography
   - Click "Insert Bibliography" to add a bibliography section
   - The bibliography will automatically include all cited papers
   - Click "Refresh" to update citations and bibliography

4. Customize Style
   - Choose from popular citation styles like APA, MLA, Chicago etc.
   - Click "More Styles..." to view additional citation styles
   - The changes will apply to both citations and bibliography

## Supported Citation Styles

The plugin includes several popular citation styles by default:

- American Medical Association 11th edition
- American Political Science Association
- American Psychological Association 7th edition
- American Sociological Association 6th edition
- Chicago Manual of Style 17th edition
- IEEE
- Modern Language Association 8th edition
- Nature

Click "More Styles..." in the style selector to access additional citation styles from the Zotero Style Repository, which provides thousands of CSL (Citation Style Language) citation styles, including journal-specific styles and regional citation formats.

## Requirements

- ONLYOFFICE Document Server v6.0 or higher
- Internet connection to access arXiv API
